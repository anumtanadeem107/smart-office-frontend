SMART OFFICE FRONTEND

1. Extract the ZIP.
2. Open the office-project folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: node server.js
5. Open http://localhost:3000 in your browser.

Node.js must be installed. No npm install is required.
If port 3000 is in use, stop the other server or change PORT in server.js.

Demo usernames: admin, manager, employee
Demo password for all accounts: Office@123

This package contains the four code files from the preceding chat message.
It is a frontend demo with browser-local storage and simulated login.
MySQL and secure server-side authentication are not included.
Use fictional data only.

Create a User account first, then link it to an active Employee profile.
To restore initial demo records, sign out and select Reset demo data.
